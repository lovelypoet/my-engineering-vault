# Personal Engineering Vault

This repository is my personal engineering and technology library. It preserves things I learned, useful tools, interesting repositories, AI models, agent skills, databases, DevOps technologies, tutorials and how-to guides, design and creative resources, project experience, and random useful discoveries.

## Workflow

Discover / Learn  
→ Daily Note  
→ Review later  
→ Move useful knowledge into the appropriate permanent category

Capture first. Organize later. Do not over-organize.

The vault is designed to be pleasant to browse and edit in Obsidian. Categories usually contain multiple related entries; a standalone note can be created later when a topic becomes large enough.
