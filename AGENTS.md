# Agent Guidance

This is a personal knowledge vault, not an AI-first database.

- Preserve the existing human-friendly organization.
- Search existing notes before suggesting technologies.
- Prefer things marked Tried, ✅ Use, or ⭐ Favorite over things merely Saved.
- Do not reorganize the vault without explicit instruction.
- Do not delete or rewrite personal notes without explicit instruction.
- Keep additions concise and human-readable.
- Update an existing category file instead of creating many tiny files.
- Create a standalone file only when a topic becomes large enough to deserve one.
- Preserve Obsidian [[internal links]].
